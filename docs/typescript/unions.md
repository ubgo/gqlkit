# TypeScript: unions and interfaces

A field that returns a GraphQL union, such as `search(term: String!): [SearchResult!]!` with `union SearchResult = Todo | User`, gets a selector with one `on<Type>()` method per member. Each call adds an inline fragment (`... on Todo { ... }`) and adds that member's selected fields to the result type. `__typename` is always requested, so the result is a discriminated union you narrow with `switch (hit.__typename)`. Interfaces work the same way, plus their shared fields; see [Selecting fields, Step 6](selecting-fields.md#step-6--self-referencing-fields-and-interfaces).

You want this page for search results, feeds, `node(id)` lookups, or any field whose value can be one of several types.

## Before you start

- A TypeScript SDK generated by a gqlkit release with union support. Older SDKs typed unions as `any[]` and sent no selection set at all, which every server rejected; regenerate if your `search()` builder has no `select()`.
- mockapi running (`task mockapi:run`) for the sample.

Snippets are quoted from [example-ts/cmd/samples/unions.ts](../../example-ts/cmd/samples/unions.ts):

```ts
const qr = new QueryRoot(new GraphQLClient(MOCKAPI_ENDPOINT));
```

## Step 1 — Select fields per member and narrow on `__typename`

```ts
async function searchByMember(): Promise<void> {
  const hits = await qr
    .search()
    .term(SEARCH_TERM)
    .select((r) =>
      r
        .onTodo((t) => t.id().text().done())
        .onUser((u) => u.id().name()),
    )
    .execute();

  for (const hit of hits) {
    // __typename is always selected, so it narrows each hit to its member.
    switch (hit.__typename) {
      case "Todo":
        console.log(`todo ${hit.id}: ${hit.text} (done: ${hit.done})`);
        break;
      case "User":
        console.log(`user ${hit.id}: ${hit.name}`);
        break;
    }
  }
  assert.ok(hits.some((h) => h.__typename === "Todo") && hits.some((h) => h.__typename === "User"));
}
```

The type of `hits` is `({ __typename: "Todo"; id: string; text: string; done: boolean } | { __typename: "User"; id: string; name: string })[]`. Reading `hit.text` before narrowing to `"Todo"` is a compile error.

The document sent:

```graphql
query Search($term: String!) {
  search(term: $term) {
    __typename
    ... on Todo {
      id
      text
      done
    }
    ... on User {
      id
      name
    }
  }
}
```

## Step 2 — Select only the members you need

Members you do not call `on<Type>()` for are still returned, but with nothing except `__typename`. Their type stays `{ __typename: "Todo" }`, so the compiler keeps you from reading fields you never asked for:

```ts
async function oneMemberOnly(): Promise<void> {
  const hits = await qr
    .search()
    .term(SEARCH_TERM)
    .select((r) => r.onUser((u) => u.name()))
    .execute();

  const todos = hits.filter((h) => h.__typename === "Todo");
  console.log("todo hits without a fragment:", JSON.stringify(todos));
}
```

## Step 3 — No `select()` sends `{ __typename }`

Unlike an object field, a union or interface field may run without `select()`: the builder always requests `__typename`, so the query is valid and tells you which members matched:

```ts
async function typenameOnly(): Promise<void> {
  const kinds = await qr.search().term(SEARCH_TERM).execute();
  console.log("kinds:", kinds.map((h) => h.__typename).join(", "));
}
```

## Pitfalls

- **Add a `default` branch if the server can grow.** The result type lists the members your SDK was generated with. If the server adds a member later, values with the new `__typename` still arrive, and a `switch` without a `default` silently skips them until you regenerate.
- **Call each `on<Type>()` once.** A second `onTodo()` replaces the first fragment's selection in the query (the fragment is keyed by its head, `... on Todo`), while the type adds both callbacks' fields.
- **An interface field that clashes with a member method gets an `_` suffix.** If an interface declares a field called `onTodo`, its selector method becomes `onTodo_()`, so the generated `on<Type>()` methods keep their names.
- **`types/index.ts` has the full union type.** `export type SearchResult = Todo | User;` is the unnarrowed shape, useful for function parameters that accept any member. It has no `__typename`; use the narrowed result type from `execute()` when you need to discriminate.
- **`executeRaw()` returns the same data, untyped.** It is handy for logging, but you lose the discriminated type.
