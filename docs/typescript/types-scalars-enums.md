# TypeScript: types, scalars and enums

The generator turns every named type in your schema into TypeScript: object and interface types into interfaces in `sdk/types`, input types into interfaces in `sdk/inputs`, enums into TypeScript `enum`s in `sdk/enums`, unions into union types, and scalars into type aliases in `sdk/scalars`. This page shows how to bind a custom scalar to your own type, how to make that binding convert values at run time with a codec, how enums and nullable values are typed, and how to loosen nullable typing while migrating older code.

## Before you start

- A generated SDK and its `config.jsonc`; see [Getting started — TypeScript, Step 4](../getting-started-typescript.md#step-4-configure-scalar-type-mappings). Every key of `config.jsonc` is listed in [config.jsonc and scalar bindings](../cli/config.md).
- mockapi running (`task mockapi:run`) for the samples.

Snippets come from [example-ts/cmd/samples/scalars.ts](../../example-ts/cmd/samples/scalars.ts), [example-ts/cmd/samples/enums.ts](../../example-ts/cmd/samples/enums.ts), the codec module [example-ts/codecs/datetime.ts](../../example-ts/codecs/datetime.ts) and the example's [config.jsonc](../../example-ts/cmd/generate/config.jsonc).

## What gets generated

| GraphQL | TypeScript | Where |
| --- | --- | --- |
| `String`, `ID` | `string` | built in |
| `Int`, `Float` | `number` | built in |
| `Boolean` | `boolean` | built in |
| custom scalar with a binding | your type, as an alias or an import | `sdk/scalars` |
| custom scalar without a binding | `any` | `sdk/scalars` |
| `enum Role { ADMIN USER GUEST }` | `enum Role { ADMIN = "ADMIN", ... }` | `sdk/enums` |
| `type Todo`, `interface Node` | `interface Todo`, `interface Node` | `sdk/types` |
| `union SearchResult = Todo \| User` | `type SearchResult = Todo \| User` | `sdk/types`; selected with `on<Type>()`, see [Unions](unions.md) |
| `input NewTodo` | `interface NewTodo` | `sdk/inputs` |
| nullable output field `email: String` | `email?: string \| null` in `sdk/types`; `email: string \| null` once selected | `sdk/types`, narrowed results |
| nullable input field or argument | `priority?: number \| null`; setter `filter(v: TodoFilter \| null)` | `sdk/inputs`, builders |
| nullable list element `[Int]` | `(number \| null)[]` | everywhere |

## Step 1 — Bind custom scalars

Bindings live under `"bindings"` in `config.jsonc`. A string value is a TypeScript type written into `sdk/scalars` as an alias; an object with `type` and `import` re-exports a type from an npm package; adding `decode`, `encode` and `codecImport` makes it convert values (Step 2). The example's file:

```jsonc
{
  // Custom scalar → TypeScript type overrides
  // Built-in scalars (String, Int, Float, Boolean, ID) are mapped automatically
  "bindings": {
    "Time": "string",
    // Relay cursor — just an opaque string
    "Cursor": "string",
    // Import DateTime type from luxon, and decode/encode it with the codec in
    // example-ts/codecs/datetime.ts so the runtime value really is a luxon
    // DateTime. codecImport is emitted verbatim and resolved from sdk/scalars/;
    // the .js suffix matches the SDK's own relative imports.
    "DateTime": {
      "type": "DateTime",
      "import": "luxon",
      "decode": "decodeDateTime",
      "encode": "encodeDateTime",
      "codecImport": "../../codecs/datetime.js"
    },
    // Import JsonValue from type-fest and alias it as JSON
    "JSON": { "type": "JsonValue", "import": "type-fest" }
    // Metadata is intentionally NOT mapped here.
    // It will fall back to `any` in the generated TypeScript SDK.
  }
}
```

It produces this `sdk/scalars/index.ts`:

```ts
// Code generated by gqlkit. DO NOT EDIT.

export type Boolean = boolean;
export type Cursor = string;
export type { DateTime } from "luxon";
export { decodeDateTime as decodeDateTime, encodeDateTime as encodeDateTime } from "../../codecs/datetime.js";
export type Float = number;
export type GqlString = string;
export type ID = string;
export type Int = number;
export type { JsonValue as JSON } from "type-fest";
export type Metadata = any;
```

`Time` has a binding but no alias, because this schema declares no `Time` scalar; bindings for scalars the schema does not use are ignored. The imported packages must be installed in the project that compiles the SDK (`npm install luxon @types/luxon type-fest` in the example).

## Step 2 — Convert values with a codec

Without a codec, a binding changes the type only: a `DateTime` bound to luxon's class would still arrive as the ISO string the server sent. A codec names two functions in a module you write: `decode` turns each wire value into your type, `encode` turns your value back into its wire form. `codecImport` is the module path, resolved from the generated `sdk/scalars/` directory and emitted as written, so include `.js` when the SDK compiles as Node ESM. The example's module:

```ts
import { DateTime } from "luxon";

/** Zone used to read and write timestamps; mockapi sends ISO-8601 in UTC. */
const WIRE_ZONE = "utc";

/**
 * Wire → app. Throws on anything that is not a valid ISO-8601 string; the
 * runtime wraps the throw in a ScalarCodecError naming the field path.
 */
export function decodeDateTime(raw: string): DateTime {
  if (typeof raw !== "string") throw new TypeError(`DateTime: expected an ISO-8601 string, got ${typeof raw}`);
  const parsed = DateTime.fromISO(raw, { zone: WIRE_ZONE });
  if (!parsed.isValid) throw new RangeError(`DateTime: not an ISO-8601 date-time: ${raw}`);
  return parsed;
}

/** App → wire. Sends ISO-8601 in UTC, the format mockapi stores. */
export function encodeDateTime(value: DateTime): string {
  const iso = value.setZone(WIRE_ZONE).toISO();
  if (iso === null) throw new RangeError(`DateTime: cannot encode an invalid DateTime (${value.invalidReason})`);
  return iso;
}
```

The SDK calls `decodeDateTime` on every `DateTime` in a response, at any depth and in lists, and `encodeDateTime` on every `DateTime` it sends as an argument or input field. `null` never reaches either function. The result:

```ts
async function decodedValue(qr: QueryRoot): Promise<void> {
  const todo = await qr
    .todo()
    .id(SEED_TODO_ID)
    .select((t) => t.id().createdAt())
    .execute();
  if (!todo) throw new Error(`seed todo ${SEED_TODO_ID} missing`);

  // The type says DateTime, and now the value is one: luxon methods just work.
  console.log("is a luxon DateTime:", DateTime.isDateTime(todo.createdAt));
  console.log("createdAt:", todo.createdAt.toFormat("yyyy-LL-dd HH:mm 'UTC'"));
  assert.ok(DateTime.isDateTime(todo.createdAt));
}
```

`executeRaw()` skips the codecs and returns exactly what the server sent:

```ts
async function rawStaysRaw(qr: QueryRoot): Promise<void> {
  const data = await qr.todo().id(SEED_TODO_ID).select((t) => t.createdAt()).executeRaw();
  console.log("executeRaw:", JSON.stringify(data));
}
```

A decoder that throws becomes a `ScalarCodecError` that names the field path. The sample uses a fake fetch to send a bad value, because mockapi only sends valid timestamps:

```ts
async function decodeFailure(): Promise<void> {
  const badFetch: typeof fetch = async () =>
    new Response(JSON.stringify({ data: { todo: { id: "1", createdAt: "not-a-date" } } }), {
      headers: { "Content-Type": "application/json" },
    });
  const qr = new QueryRoot(new GraphQLClient(MOCKAPI_ENDPOINT, { fetch: badFetch }));

  try {
    await qr.todo().id(SEED_TODO_ID).select((t) => t.id().createdAt()).execute();
    assert.fail("an invalid DateTime must fail to decode");
  } catch (err) {
    if (!(err instanceof ScalarCodecError)) throw err;
    console.log("codec error:", err.direction, JSON.stringify(err.path));
    console.log("message:", err.message);
  }
}
```

When the bad value is in partial data next to GraphQL errors, you still catch the `GraphQLErrors`, with `err.data` set to `undefined` and the codec failure on `err.decodeError`:

```ts
async function partialDataDecodeFailure(): Promise<void> {
  const badPartialFetch: typeof fetch = async () =>
    new Response(
      JSON.stringify({
        errors: [{ message: "metadata unavailable", path: ["todo", "metadata"] }],
        data: { todo: { id: "1", createdAt: "not-a-date", metadata: null } },
      }),
      { headers: { "Content-Type": "application/json" } },
    );
  const qr = new QueryRoot(new GraphQLClient(MOCKAPI_ENDPOINT, { fetch: badPartialFetch }));

  try {
    await qr.todo().id(SEED_TODO_ID).select((t) => t.id().createdAt().metadata()).execute();
    assert.fail("a response with errors must reject");
  } catch (err) {
    if (!(err instanceof GraphQLErrors)) throw err;
    console.log("errors:", err.message);
    console.log("data:", err.data);
    console.log("decodeError:", err.decodeError?.message);
    assert.equal(err.data, undefined);
    assert.ok(err.decodeError instanceof ScalarCodecError);
  }
}
```

## Step 3 — Enums as arguments and results

Enums are string enums, so `Role.ADMIN` is the string `"ADMIN"` on the wire, and a selected enum field is typed with the enum:

```ts
async function enumArgument(): Promise<void> {
  const created = await mr
    .upsertUser()
    .name("Enum Sample")
    .role(Role.ADMIN)
    .select((u) => u.id().name().role())
    .execute();
  console.log("created user:", JSON.stringify(created));

  // The same id updates in place; the enum value on the wire is the string "GUEST".
  const updated = await mr
    .upsertUser()
    .id(created.id)
    .name("Enum Sample")
    .role(Role.GUEST)
    .select((u) => u.id().role())
    .execute();

  // `updated.role` is typed `Role`, so comparing to the enum member type-checks.
  console.log("role is GUEST:", updated.role === Role.GUEST);
  assert.equal(updated.role, Role.GUEST);
}
```

Import enums from the SDK: `import { Role } from "./sdk/enums";`.

## Step 4 — Nullable values are `null`

A selected nullable field is always present and typed `T | null`, which is what the server sends:

```ts
async function nullableFields(qr: QueryRoot): Promise<void> {
  const todo = await qr.todo().id(TODO_WITHOUT_PRIORITY_ID).select((t) => t.priority()).execute();
  if (!todo) throw new Error(`seed todo ${TODO_WITHOUT_PRIORITY_ID} missing`);

  const priority: number | null = todo.priority;
  console.log("priority:", priority);
  console.log("priority ?? 0:", priority ?? 0);
  assert.equal(priority, null);
}
```

## Step 5 — Choose how nullable fields are typed

The default, `"nullable": "null"`, gives the `T | null` types above. Code written for older SDKs, which typed nullable outputs as `field?: T`, may compare them with `=== undefined` or annotate them as `T | undefined`, and fails to compile after regenerating. For a gradual migration, `config.jsonc` can type nullable output fields as `T | null | undefined`, globally or per type or field:

```jsonc
{
  "nullable": "null-undefined",
  "nullableOverrides": {
    "Todo": "null",
    "Todo.priority": "null-undefined"
  }
}
```

A field key (`"Todo.priority"`, `"Query.requestHeader"`) beats a type key (`"Todo"`), which beats the global `nullable`. List elements always stay `T | null`, and inputs and arguments are not affected. An unknown mode, or an override naming a type or field that does not exist, is rejected when the config loads. The example SDK uses the default, so this step has no runnable sample.

## Pitfalls

- **A binding without a codec is a type claim, not a conversion.** Bind classes (`DateTime`, `Decimal`, `BigInt`) only together with `decode`/`encode`; otherwise bind the wire type (`"string"`) and convert where you use it.
- **`executeRaw()` is never decoded.** It returns wire values on purpose, for logging and debugging. `execute()`, `batch()` and the partial data on `GraphQLErrors.data` are decoded.
- **`decode`, `encode` and `codecImport` go together.** A codec without `codecImport`, a `codecImport` without a codec, or a function name that is not a plain identifier is rejected when the config loads.
- **`codecImport` and `import` paths are emitted verbatim.** They are resolved from `sdk/scalars/`. Under Node ESM (`"moduleResolution": "nodenext"`), write relative paths with the `.js` extension (`"../../codecs/datetime.js"`), as the SDK's own relative imports are.
- **Decoders run on untrusted input.** Check the value's type and validity and throw a clear error, as `decodeDateTime` does; the runtime wraps the throw with the field path.
- **The example has no `DateTime` argument or input field,** so `encodeDateTime` is wired but never called by a sample. Encoding runs on scalar arguments and on codec fields of input objects, including nested inputs.
- **An unmapped custom scalar is `any`.** `Metadata` above has no binding, so `todo.metadata.anything.at.all` compiles. Bind every custom scalar, even to `unknown` (`"Metadata": "unknown"`), to keep type-checking on.
- **Union bindings in lists are parenthesised.** A binding such as `"ID": "string | number"` used in `[ID!]` renders as `(string | number)[]`. Versions before the fix for [issue #5](https://github.com/ubgo/gqlkit/issues/5) rendered `string | number[]`; regenerate if your SDK has that.
- **Enum names are copied as they are.** `enum Role { ADMIN }` gives `Role.ADMIN`, not `Role.Admin`.
