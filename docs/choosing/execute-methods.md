# Which method to call: typed builder, raw result, batch or a hand-written document

A generated SDK gives you several ways to send an operation. They all go through the same client (same endpoint, headers and timeouts); they differ in who writes the document and what type comes back. This page helps you pick one for each call site.

## Before you start

You need a generated SDK and a client. The guides for the client are [Go client](../go/client.md) and [TypeScript client](../typescript/client.md).

## If X, then Y

- **If the builder covers the operation**, use the typed `Execute` / `execute`. Every other row trades type checking for flexibility.
- **If you need a union or interface member's fields**, use the typed `On<Type>` / `on<Type>` selectors; raw `... on Type` children are no longer needed.
- **If you need named fragments, directives (`@include`, `@skip`) or a subscription**, the builders cannot express them; write the document by hand and send it through the same client.
- **If you write documents by hand in many places**, that is a sign the schema changed under the SDK; regenerate first (see [When to regenerate](./when-to-regenerate.md)) and see if the builder now covers it.
- **If you only need to log or snapshot what is sent**, print `BuildQuery()` (Go) rather than wrapping the transport.

## Pitfalls

- **`ExecuteRaw` returns the whole `data` object**, keyed by the root field name, not the root field's value: read `raw["todos"]`, not `raw[0]`.
- **A raw document skips the generated variable types.** Arguments you inline into the string are not escaped for you; pass them as variables.
- **`client.execute<T>` in TypeScript is an unchecked cast.** Validate the shape at the boundary if the value comes from a server you do not control.
- **Go `Execute` drops data when there are errors.** It returns `GraphQLErrors` and no result. Use `ExecuteWithPartialData` or a batch when you need both.
